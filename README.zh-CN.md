## 主要项目

### [DSH Cost Meter](https://github.com/Han-1413141/dsh-cost-meter)

查看 AI 编程费用花在了哪里。为 DeepSeek Harness 提供会话费用、Token 用量、预算、渠道余额和 Coding Plan 额度展示，支持中英文界面。

- 区分订阅用量与按量付费支出。
- 查看各模型费用与历史用量，支持自定义价格。
- 根据社区问题持续修复，并记录每次变更。
